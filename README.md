## 问题1 定义幻觉类型

幻觉的定义：AI回答的内容与事实相违背，但是在回复内容中并没有怀疑错误的存在。简单来说就是“正经的胡说”
在给定的文档里，可以分为五种幻觉
1. 虚构事实
- 无中生有的回答，例如h18 h19，AI在无参照的情况下给出了自信的回答，明显是基于预训练的内容而非知识库内容
2. 参数和事实错误
- 回答内容和知识库指示相违背或么有正确理解，包括政策和参数等，例如h17和h13
3. 政策规则错误
- 回答内容不完整，例如h01，只回答了部分信息，缺少了关键信息
4. 安全风险
- 例如h13，对于普遍的风险没有清晰的辨认
5. 未采纳文档
- 例如h20，根本没参考文档信息

## 问题4 误判原因
个人分析：单纯判断幻觉问题的话是没有产生误判的。其中我对于幻种类的划分和ground_truth有所不同，我没有从“优惠”或者“政策”等角度去划分，而是从“事实”或者“参数”等角度去划分。

# 脚本说明：
检验脚本分为eval_script和eval_verify，前者属于分析回答是否有幻觉并分类，后者属于通过该回答是否是幻觉来评测准确率/精确率/召回率/F1这几个指标作为检出率参考

## eval_script运行方式
在文件夹新增input.json，内容和题目的replies保持一致。在.env中配置DEEPSEEK_API_KEY，EEPSEEK_MODEL，MAX_TOKENS。之后运行 python eval_script.py 获取output.json即可

## 检出率
检出率数据参考output_eval.json即可。可以参考summary里面包含各类参数。计算方法基于答案和output.json中对于幻觉案例的判断结果进行对比得到（TP=18, FP=0, FN=0, TN=2）总结而来。具体逻辑位于eval_verify.py文件中
